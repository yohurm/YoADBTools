# 模块：命令终端

- 领域：`yohu-domain` 命令库 / `GroupExecutor`（多设备并行、组内串行；不判定成败、不因失败中断。组条目之间无额外间隔；命令块步间可按 `COMMAND_BLOCK_GAPS_MS` 等待）
- 运输：`yohu-adb` 实现 `Runner`
- UI：`@yohu/module-terminal`；选择模式 `multiOptional`。主视图左右分栏都挂 `YoPanel title`（命令库 / 执行结果）；左栏宽 `--yohu-layout-sidebar`（240vp）。禁止命令库无标题。命令库标题行右侧 `YoSearch slot=entry`，栏下 `slot=bar`（库内 `YoCollapse`）；过滤在 `search.ts`（把组/叶编成 `SearchDocument`，组名字段命中保留整组）。禁止模块再叠 IconButton + Collapse + TextField。命令管理三栏标题仍走 Toolbar + Subheader
- 数据：`DataRoot/modules/adb-terminal/config/library.json`（schemaVersion 3 only；缺文件写默认库；损坏或其他 schema 则 `.corrupt-<ts>` 备份后写默认库。无 v2 迁移）
- 编辑即快照：深拷贝、全量提交、取消零污染。组只存名称。组下叶子是同级「命令」或「命令块」：命令只存名称 + 一行 template（可含 `{0}`）；命令块存名称 + `steps[]` + 块级 `gap_ms`（`0/200/500/1000/2000/5000`，只发生在步与步之间）。不配置标签、成功/失败正则、输入提示、组条目间隔、失败中断
- 结果：统一输入/输出块（一次 `>>>` + 一条多行 `<<<`，标识 + 时间 + 内容），自上而下；空态在视口正中。库命令与发送栏同一 `send` → `terminal.exec`。IO 行只存墙钟毫秒 `at`；展示走 `@yohu/api` `formatClockFromMs`，形状由设置 `terminal_time_format` 投影（默认 `time_millis` = `HH:mm:ss.SSS`；可选 `time` / `datetime_millis` / `datetime`）。日志清单按 `log_time_format` 投影（默认完整墙钟）；文件日期只到秒
- 发送栏：贴右双轴开合（`yohu-recipe-inline-end`：宽 compact↔100%，高 0fr↔1fr；空态跟随挤位）；点预设命令或命令块在输入框上方排队（`YoListPresence` + `YoChip`）；点组只开合目录，不入队。纸飞机发送队列与草稿（空内容向右，有内容 `yohu-recipe-send-aim` 朝上）。composer 弱多行走 `YoTextField multiline rows={1}`（不是 YoTextArea，禁止模块再挂 textarea 壳）。抬高/降低是 TextField 用后高（`field-sizing` + `contain: inline-size` + `YoGrow` `spatialGrow` 300ms 长尾弹簧写宿主 `height`，铬跟锁行且绘制铺满锁行 CSS 盒，禁止量 px viewBox + meet；字贴底与发送钮同基线；发送栏开行禁止 `min-content` / stretch），模块不包 Grow / Travel、不写 `height`。发送钮贴底（`align-items: flex-end`）。模块 CSS 只给发送栏字段槽铺宽与等宽字体。结果区新 IO 块升起，清屏直切。流/排队首项身份走 Presence 宿主 `data-first`（含出场中），禁止点 `.yohu-presence`。设置 `terminal_prepend_adb`（默认关）决定是否在发送前加上 `adb`
- 占位符：落盘仍是 `{n}`（schema 3；不存 `{1-0}`）。每个出现的 `{n}` 是独立参数，不是「最大下标 + 1」个空位；`{13}` 只占一个槽，不发明 `{0}`…`{12}`。命令的 `params[{index,description}]` 挂在命令上；块的 `params` 挂在该步上（空说明或不在本步槽位的项不落盘；旧块级 `params` 忽略）。domain `placeholder_slots` / `insert_placeholder` 只看一条模板；块填参身份是 `StepParamSlot`（步从 1 计 + 本步 `{n}`），标签 `1-0`。`CommandBlock::fill` 按步切开 `string[]`，同号 `{0}` 各吃各的值。`{n}` / 拆行 / 去前导 adb / 拼输出在 `@yohu/api` `command-line`（镜像 domain testdata）。模块 `command-line.ts` 只做 `adb` 展示前缀、填参栏字段、复制。命令管理具体命令标签为 `具体命令（{n}代表使用命令时需要填入的独立参数）`，按钮文案「插入参数」（本行空号）。`ParamDescriptions` 跟模板走：命令 `{n}`，步骤 `1-0`。填参弹窗列出原始命令与 `FillField`（有描述则跟在标签后），不展示预览行。单条命令 store `enqueueCommand`（内部 `fillTemplate`）后 `send` → `terminal.exec`；命令块一次按步序填值后走 `block.run`。组走 `group.run`（占位符不足由 IPC 错误投影，store 不再预检）。两边共用 `command_fill.json` / `command_placeholders.json` / `command_body.json` / `combine_output.json` / `align_params.json` / `command_split.json`。执行载荷 `toExecLine` 在 `@yohu/api`（设置打开才补 `adb`）
- 命令管理：`YoDialog` fill（`MANAGER_DIALOG`）`bodyOverflow="hidden" bodyPad="none"`。层与裁切走 Dialog Portal + fill 定高，模块不自写 overlay。栏标题是 `YoToolbar pad="xs"` children 里的 `YoSubheader`（组/条目常驻；右栏有 `editorPaneTitle` 才挂；`pad=xs` 贴栏素底，与清单名 12vp 对齐，禁止再套灰带），禁止 `YoToolbar title` / 右栏 `YoPanel title`，禁止点 `.yohu-toolbar`。结果区 `YoPanel overflow="hidden"`。参数对话框只读受控 `values()`。禁止点 `__body` / `:has`，禁止 `querySelectorAll("input")`。中栏条目 Ctrl 点选 / Shift 范围选。右键走 `terminal.command`（复制所选具体命令 / 删除所选）；场景表在模块根 `menu.ts`
- **命令管理分层**（对标 files：`model` / `store` / `menu.ts` / 列视图；不新开 Yo 组件、不把 menu 挪出模块根）
  - `search.ts`：命令库 → `SearchDocument` 适配；引擎走 YoSearch 公开面（含拼音）。不写 DOM、不放选区、不实现分词/评分/拼音
  - `LibraryPane.tsx`：命令库 `YoPanel` + 分槽 `YoSearch`（入口 / 栏）。树在 `CommandTree`
  - `draft.ts`：只做 DTO ↔ 草稿、`empty*`、`nextDraftId`。`DraftStep` 持本步 `params`；`DraftBlock` 不持块级 `params`。不放选区、不放拖动几何
  - `manager/keys.ts`：命令管理绑定表；Dialog 内不用 `whenList`（会被 `inDialog` 挡掉）
  - `manager/store.ts`：`createCommandManagerStore()` 持草稿 + 中栏选区 + `open`。工厂留给单测；模块会话单例 `commandManagerStore`。选区直接调 YoUI `nextKeys`。换位 `moveItemTo` 来自 `@yohu/ui`。**不** import 运行时终端 store；**不**开菜单、不写剪贴板、不查 DOM。从关闭到打开 `open(library)` 切快照；已打开再 `open` / 切回不自动 `load`。页脚取消 `requestClose` 只关 open，`finishClose` 在 onExitComplete 丢草稿
  - `manager/editor-target.ts`：选区一次算出右栏目标（empty / multi / group / command / block）与页眉。禁止在 JSX 里嵌套 Show 猜 `kind`
  - `manager/{Group,Entry,Editor}Column.tsx` + `CommandEditor.tsx` + `BlockEditor.tsx` + `BlockSteps.tsx` + `TemplateField.tsx`：三栏都是 `YoPanel variant=pane`（高度与圆角对齐）。栏标题是 `header` 里 `YoToolbar pad="xs"` + `YoSubheader pad="flush"`（贴栏素底，圆角只属面板），禁止 `YoToolbar title` / 右栏 `YoPanel title`。右栏 `createMemo(editorTarget)` 后互斥 `Show` 分发；命令表单在 `CommandEditor`，块表单在 `BlockEditor`。组/条目清单是 `YoVirtualList`（单选 `selectedKey` / 多选 `selectedKeys` + `pointerSelectMode`）。中栏条目名之间走 `tone=list` hairline，清单背板 canvas；禁止自挂 `ul`/`YoIndicator`，不走 `YoColFrame`。组与条目整行拖动走 `YoVirtualList.onReorder`（浮层跟指针、占位让位、缝间插条）→ `store.moveGroupTo` / `moveEntryTo`。步骤变高换位走 `YoReorderList`（同一套 L2 行盒 + binder；增删由行内 Presence `list` 播出，与参数描述同一 `useListPresenceSlots`；禁止常驻手柄、禁止模块再包 `YoListPresence`、禁止再写 `dropIndexFromCenters` 第二套几何）。`TemplateField` 在本行插入下一个 `{n}`（`insertPlaceholderAtDisplay`）。命令描述在 `CommandEditor`；步骤描述在该步里，标签 `1-0`。禁止条目级并集、禁止 View 再传 `usedSlots`
  - `ParameterDialog.tsx`：填参弹窗。View 只交 `entry` 并提交 `values`；原文 / `FillField` 由 `entryTemplates` + `entryFillFields` 算出，不画预览
  - `manager/ParamDescriptions.tsx`：每个本行槽位一条描述字段（命令 `{n}`，步骤 `labelOf` → `1-0`），紧跟具体命令/该步，与名称同一条纵向表单（pane 字段 hug 靠顶，`.yohu-cm__template` 只铺宽）
  - `manager/Workspace.tsx`：三栏 + `attachPanelKeys`。不开 Dialog、不保存、不开菜单
  - `CommandManager.tsx`：薄 fill Dialog，绑 `commandManagerStore`。禁止 `open && !wasOpen` 自动 `load`。保存 `terminalStore.save(store.library())`、`openContextMenu(terminalCommandMenu)` + clipboard。`view.test.ts` 在此文件扫到 `openContextMenu` / `terminalCommandMenu`，键位在 Workspace，且不含 `<YoContextMenu`
  - `store.ts`（模块根）：运行时终端（队列 / `exec` / `block.run` / `group.run` / 命令库持久化）。等待槽只认 `run_id`（`run-wait.ts`：快照有该项且 `!active`）。`group/progress` 只画行。缺任务、进度计满、`group.cancel` 失败都不 settle。取消入口在模块页眉（`group.cancel`）。与命令管理草稿 store 分开
  - **设计前链路（发送）：** `TerminalView` 私有 `queue` + `sendAll` 串 `await runBlock`；`block.run` 只返回 `run_id`，队列下一项与 GroupExecutor 并发。点组 `g:` 直接 return。`runCommand` 与 View `fillTemplate+send` 双轨。
  - **设计后链路（发送）：** 点叶子 → `CommandTree` →（需填值则 `ParameterDialog` →）`store.enqueueCommand` / `enqueueBlock`（填充只在 store）→ `Composer` 纸飞机 `store.sendAll` → `send` → `terminal.exec` → `combineOutput` 与 domain 同一 testdata。草稿同行。点组 `g:` 只开合，`onSelect` 直接 return，不 `enqueueGroup`。
  - **设计前链路（组）：** 点组无执行入口；`runGroup` / `cancelGroup` 仅单测。
  - **设计后链路（组）：** 点组只开合，不入队。`runGroup` / `enqueueGroup` 仍在 store（队列若已有组项则 `sendAll` → `group.run` 得 `run_id` → `TaskCenter` 抄写 `TaskInfo.run_id` → 等 `task/summary` 中该项 `!active` → 下一项）。页眉「取消」→ `cancelGroup`（当前 `run_id`）；失败只打日志，不 settle。占位符不足走 IPC 错误文案。
  - **设计后链路（管理寿命）：** 点「命令管理」`commandManagerStore.open(library)` 切快照。`ModuleStage` 切走卸 View，草稿与 `open` 留在模块单例。切回若 `open` 仍为真则 Dialog 再投影同一份草稿，禁止 effect 再 `load`。页脚取消 `requestClose` 只关 open，`finishClose` 在 onExitComplete 丢草稿。不要改 workbench。
  - **设计前链路（管理）：** `TerminalView` → 单文件 `CommandManager` 同时持草稿、多选、步骤 pointer 几何、`openContextMenu` + clipboard、三栏 JSX；`draft.ts` 夹拖动几何。右栏再用嵌套 `Show` + `kind === "command" ? entry : undefined` 拆命令/块，命令分支被吃掉后 JSX 对不上。问题：一层以上塞进同一文件，选区形态写在标签树里
  - **设计后链路（管理）：** `TerminalView` → `commandManagerStore.open(library)` → fill Dialog（Portal）投影 `open` → `ManagerWorkspace`（键位 + 三栏）→ `manager/store`（草稿/选区）→ `createMemo(editorTarget)`（empty/multi/group/command/block）→ `EditorColumn` 互斥 `Show` → `CommandEditor` / `BlockEditor`；右栏 `TemplateField` 写本行 `{n}`，`ParamDescriptions` 读该模板槽位（步骤 `1-0`）；右键 Dialog 打开 `menu.ts` 场景；复制 `commandCopyLines`；删除 `removeEntries`；保存 Dialog → `errorText` → `terminalStore.save` → `commandlib.save`。组/条目拖动 `YoVirtualList.onReorder` → `store.moveGroupTo` / `moveEntryTo`。步骤拖动 `BlockSteps` → `YoReorderList.onReorder` → `store.moveBlockStepTo`（描述跟步骤走，标签按新位重算）。点带参叶子 → `ParameterDialog`（`entryFillFields`）→ store 入队。清单行高 `controlRowHeight()` 跟 `getDensity()`。
  - **设计后链路（换位）：** 定高组/条目清单 `YoVirtualList.onReorder`（浮层 / 占位 / 让位 / 插缝）→ `moveGroupTo` / `moveEntryTo`。变高步骤 `YoReorderList`（同一套 L2 行盒 + binder；行内 Presence `list` 播出增删；行内 input / 删除钮不抢换位；`Ctrl/Meta+↑/↓`）→ `moveBlockStepTo`。禁止常驻手柄，禁止模块 `querySelector` + `dropIndexFromCenters` 第二套几何。
  - **设计后链路（Chip）：** 队列项 `YoChip` `leading`（命令 `terminal` / 块 `block` / 组 `folder`）+ `onDismiss` → `removeQueued`。关闭走库内 `DismissMark` / `.yohu-recipe-dismiss`，流内右侧；禁止 `position: absolute`、禁止 Chip 原生 `title`、禁止模块再画圆钮。命令块身份一律 `block`（提示符 + 三行），禁止 `list` / 碎角叠方块。
- IPC：`terminal.exec` / `block.run` / `group.run` / `group.cancel` / `commandlib.*`；进度 `group/progress`（块与组共用，取消同一 `group.cancel`）。`terminal.eval` 仍可按库 id 填充执行，UI 不走这条。间隔与多步只在 domain 编排，禁止 UI `setTimeout` 串 `terminal.exec`
