# ADR-v6-045 — 三端安装包 CI 与 Release

- **状态：** 已接受
- **日期：** 2026-10-10
- **补充：** [ADR-v6-014](../README.md)（Windows NSIS）、[ADR-v6-029](ADR-v6-029.md)（macOS）、[ADR-v6-043](ADR-v6-043.md)（Linux）、[ADR-v6-022](ADR-v6-022.md) / [ADR-v6-035](ADR-v6-035.md)（更新通道）

## 背景

产品交付 Windows NSIS、macOS DMG、Linux `.deb`（`yohu-update` 的 `InstallerKind` 与 `conventional_installer_name` 已认三端）。CI 三端验证早有，但打包与发版只挂 Windows NSIS；Linux / macOS 只能本机 `cargo tauri build`，Release 的 `update-manifest.json` 只有 `windows-x86_64`。

## 决策

1. **CI 打包与验证分 job。** `verify` / `verify-macos` / `verify-linux` 不变。另加 `package`（NSIS）、`package-macos`（DMG）、`package-linux`（deb），均 `needs` 对应验证；仅在 `push` 到 `main` 或 `workflow_dispatch` 跑（PR 不打安装包，与现 Windows 纪律一致）。
2. **Release 矩阵构建 + 汇总发布。** 打 `vX.Y.Z` 标签后，Windows / macOS / Linux 并行 `cargo tauri build`，产物上传为 job artifact；`publish` job 在 `ubuntu-latest` 汇总，生成多平台 `update-manifest.json`，再 `gh release create` 挂上全部安装包与 manifest。
3. **约定文件名不变。** 与 `yohu-update::conventional_installer_name` 对齐：
   - Windows x64：`YohuAdbTools_{ver}_x64-setup.exe`
   - macOS arm64：`YohuAdbTools_{ver}_aarch64.dmg`
   - macOS x64：`YohuAdbTools_{ver}_x64.dmg`（本流水线默认 `macos-latest` = arm64，不打 Intel；键位仍留给本机或后续 runner）
   - Linux x64：`YohuAdbTools_{ver}_amd64.deb`
   - Linux arm64：`YohuAdbTools_{ver}_arm64.deb`（本流水线默认 `ubuntu-latest` = amd64）
4. **manifest 平台键不变。** `windows-x86_64` / `darwin-aarch64` / `darwin-x86_64` / `linux-x86_64` / `linux-aarch64`（ADR-v6-035 / `platform_manifest_key`）。生成脚本：`scripts/build-update-manifest.sh`（Release 汇总用）；`scripts/build-update-manifest.ps1` 保留本机 Windows 单包场景，并支持多 `-Platform`。
5. **macOS 不签名、不公证。** 仓库未配置 Apple Developer 证书与公证密钥时，CI 产出**未签名** DMG。用户首次打开可能需在「隐私与安全性」里允许，或右键打开。签名 / 公证另开 ADR 与 secrets，不在本决策偷偷跳过检查。
6. **发布仓库 slug 仍按 ADR-v6-022 / 044。** manifest 里的下载 URL 默认 `yohurm/Windows-YoADBTools`（与应用内检查一致；GitHub 重命名后会跳到当前仓）。可用脚本参数覆盖为实际 `GITHUB_REPOSITORY`。

## 后果

- 打标签一次即挂三端安装包；Linux / macOS 检查更新可走静态 manifest，不再只能靠 Atom 约定文件名碰运气。
- CI 推 `main` 会多跑两台打包机（时长与缓存成本上升）；PR 仍只验证。
- 未签名 macOS 包不能当 App Store / 企业分发；外测需在发行说明写明 Gatekeeper 步骤。

## 不做

- AppImage / MSI / 通用二进制（universal）DMG
- 在 Linux runner 上交叉编 macOS
- 把 OpenH264 打进 deb（ADR-v6-042 / 044）
- 改应用内默认发布仓库名（等 022 另修）
