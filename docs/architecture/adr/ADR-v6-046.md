# ADR-v6-046 — 日志模块架构解耦与长日志时间格式缺陷修复

- **状态：** 已采纳
- **日期：** 2026-11-19
- **关联：** ADR-v6-006、ADR-v6-007、ADR-v6-016、ADR-v6-021、ADR-v6-041、[modules/logs.md](../modules/logs.md)、[ipc.md](../ipc.md)

## 背景

1. **缺陷：** 真机 `adb logcat -v long,uid,year` 存在 Tag 自身含 `/` 的合法头（如 `I/OkHttp/4.9.0`、`I/com.example/Foo`）。`yohu-logsrv` 的 `parse::take_level_tag` 用 `rest.rfind('/')` 取「级别/Tag」分隔斜杠，会把 Tag 内的最后一个 `/` 当分隔符，导致整条 header 解析失败；`assembler` 遂把这条真 header 当作上一条消息的正文压入 body。表现为**下一条记录的时间戳文本落到上一条消息尾部（时间卡在后面）**、该条记录整体丢失、格式错乱。AOSP `logprint.cpp` 的 `%-8.*s` 不截断 Tag，AS `LogcatHeaderParser` 的 `TAG = (.*?)` 接受任意 Tag 内容；差异只在解析层。
2. **结构：** 日志模块若干文件承担多层职责：`yohu-logsrv/capture.rs` 同时是槽位机 / 环 / 窗口索引 / 导出 / 进程索引 / 包名；UI `workspace.ts` 混模型 + 会话 + 文档投影 + 跟滚 + 设备投影 + 页装配；`capture.ts` 混 IPC 启停 + 设备写 + 事件订阅 + DOM 生命周期 + 页缓存；`LogAnalyzerView.tsx` 混渲染 + 测量 + 复制 + 导出 + 右键装配。另有未接线的第二套投影（`panel.ts` 的 `projectWindow` 系列）与死双轨 `AppEvent::LogBatch` / `log.replay`。

## 决策

### 1. 解析层修复（唯一一跳）

`parse::take_level_tag` 改用**第一个** `/` 作分隔符：`rest = <ids> <LEVEL>/<tag>`，`ids` 不含 `/`，`/` 右侧全部是 Tag。补测试 `tag_can_contain_slash`、`assembler::header_with_slash_tag_closes_previous_record`。同时让未知单字符字母优先级归一到 `'?'`，避免优先级表外的头整条被吞。

### 2. Rust 采集服务按职责拆分

`CaptureService` 退化为组合门面，只转发：

- `slots::CaptureSlots` — 槽位 Empty/Starting/Live/Stopping + generation + start/stop/adopt/abandon/release；`CaptureSlot` 持有 capture/index/**batch** 三路句柄，stop 时全部 join 收敛。
- `ring_store::RingStore` — 每设备环与容量（`RingBuffer` 保留）。
- `windows::WindowBook` — 窗口命中索引（不变）。
- `export::LogExporter` — 环上过滤 + 流式导出；落盘在 app 层 `spawn_blocking`。
- `index::ProcessIndexService` — 进程索引（降级可恢复：成功/失败都按 `(entries, degraded)` 变化上报）。
- `record::LogRecord` — crate 私有入口模型；`follow` 边界一次性 `into_wire()` 成 `LogLine`，wire 与存储模型分家。
- `limits` — 通道容量 / 字节估算常量池。

续流：`FollowEnd::Terminal` 表达永久运输失败（`ToolUnavailable`/`CandidatesFailed`/`UnsupportedShell`），按 `Offline` 同路释放槽位并推 Stopped，不再永久 250ms 热重启。`resume_skip` 只用最近一条非空 `ts` 的记录，`-T` 为空则不带。

### 3. UI store 按切片拆分

`ui/packages/modules/logs` 单向切片（`log-model ← device-projection ← session-lifecycle ← panel-projection ← follow-state ← workspace`）：

- `log-model.ts` 模型与 `SYSTEM_SESSION_TITLE`。
- `device-projection.ts` 设备投影单源（模型 + 读 selector + 写 setter）。
- `session-lifecycle.ts` 会话查找与 CRUD 唯一实现。
- `panel-projection.ts` 文档/可见区投影（只消费 `panel.ts` 纯函数）。
- `follow-state.ts` 跟滚/冻结唯一状态机。
- `workspace.ts` 只装配 + 转发；`capture.ts` 只装配 + 窗口命令。

`capture` 拆 `capture-orchestrator.ts`（IPC 启停/世代对账）、`viewport-page.ts`（页拉取代际）、`capture-subscriptions.ts`（事件订阅）。**IPC/store 层禁止 import `@yohu/ui` 的 DOM 能力**：可见性监听归 `LogAnalyzerView`（View），调 `resumeVisible()`。

`LogAnalyzerView` 抽 `use-log-view-layout.ts`（测量/ResizeObserver）、`copy-controller.ts`（复制）、`export-action.ts`（导出对话框）；`editor/format.ts` 按列几何/着色/文本拆 `format-columns/format-paint/format-text`。

### 4. 删除死双轨

删除 `AppEvent::LogBatch` / `LogBatchPayload` / `LOG_LINES` / protocol `LogBatch` / `ReplayRequest` / `CaptureService::replay` / `log.replay` 命令 / `@yohu/api` 的 `onLogBatch`/`logReplay`/`LogBatch`/`ReplayRequest`，以及 `panel.ts` 未接线的 `projectWindow`/`selectHits`/`splitHitsForFreeze`/`mirrorCoversRange`。溢出补行与首次补页统一走 `log.window.bind` 重新登记当前窗口。

### 5. 契约孪生与错误

页宽 `LOG_PAGE_LINES` 收敛到 `@yohu/api` 单一常量，`viewport.ts` 引用，不再自写 `80`（ADR-v6-047 起该常量已删除，真机测试改用本地常量）。`LogError::WindowNotRegistered` 让「窗口未登记」在 core 表达、`ipc_map::ipc_log` 单点映射 NotFound；`LogError::ExportIo{path}` 与 `ipc_adb(BadExit)` 不再把 OS/stderr 原文交给 UI（只进 tracing）。任务中心按 `(serial, generation)` 收口，迟到 Stopped 不误杀新任务。

## 后果

- 长日志含 `/` 的 Tag 不再吞记录；时间行不再错位。
- 采集服务/工作区/采集客户端各自单一职责；旧「整批推全文」与第二套投影无残留。
- 溢出/回补只有一条通路（`log.window.bind`），导出只在用户操作时流式落盘。

## 追加收口（wave2 残余，已全部清零）

wave2 复审识别、原拟列为下一阶段的 6 项性能/清洁度债，已在同一轮全部落地（`cargo build/test/clippy` 与 `pnpm typecheck/test/lint` 全绿、wave3 复审 CLEAN，无残留、无双轨、无 TODO）：

1. **环锁粒度**：`ring.rs::for_each_from` 改分块——每轮锁内只克隆 ≤512 行 `to_wire`，解锁后 `visit`，`cursor = 末条.seq + 1`；`windows.rs::bind` / `export.rs` 共用同一遍历；`ring.push` 不再被整段扫描阻塞。行为测试 `for_each_from_chunks_whole_ring_in_order`。
2. **`LogLine.app`**：从 `protocol/log.rs`、`record.rs`、`ring.rs` 删除（无生产者）；`ui` 的 `format-text.appNameOf` 去 `line.app` 分支。
3. **`through_seq` 双轨**：删除 `LogWindowBind.through_seq`、`Window.through_seq`、`view_end`、`LogPage.pending`；`page_all` 直接用命中长度；删除 through/pending 测试。另删 `LogWindowBind.following`、`LogLatch` 与 `log.window.latch` 死命令（跟滚/冻结已由 UI 文档自持，core 不再消费）。
4. **UI 取页/写单源**：`applyPage` 去 `mode`；删 `pullPage`/`requestPage`/`logPage`/`LogPageQuery`/`log.page`（唯一取页走 `logWindowBind`）；`capture.clearDevice` 改调 `panel-projection.resetAfterDeviceClear`；View 走 `logStore.deviceOf`；`signalCount` 唯一由可见派生、`pendingCount` 单点写。
5. **跨语言契约 fixture**：`testdata/event_names.json` 由 Rust（`core/yohu-protocol`）与 `@yohu/api` 两端测试共同断言，取消手工硬编码（`log_page_lines.json` 已随 ADR-v6-047 删除）。
6. **测试面入口/源码文本断言**：删 `capture.is_capturing`（集成测试改 `status().capturing`），`snapshot` 升为公开诊断 API；删除 `include_str!` 子串计数脆弱测试，改行为测试（分块遍历、槽位 start/stop/adopt/restart/掉线/取消等）。
