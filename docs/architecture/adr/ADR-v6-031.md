# ADR-v6-031 — 安装根与产品家园分离

- **状态：** 已接受（as-built）
- **日期：** 2026-09-10
- **补充：** [ADR-v6-014](../README.md)（NSIS）、[ADR-v6-008](../README.md)（sidecar）、[ADR-v6-022](ADR-v6-022.md)（更新缓存）

## 决策

对照 VS Code User（`%LOCALAPPDATA%\Programs\…`）、XDG（config / data / cache / state）与 Microsoft Known Folders：安装载荷与可变用户数据不得同目录。

- **安装根** `yohu_runtime::app_install_root`：Windows `%LOCALAPPDATA%\Programs\YohuAdbTools`；macOS `/Applications/YohuAdbTools.app`。
- **产品家园** `app_data_root`：Windows `%LOCALAPPDATA%\YohuAdbTools`；其下 `config/` `data/` `cache/` `logs/`。`data_root` 可改，重启生效，不搬家。
- **sidecar** 按源 size+mtime stamp 覆盖解压到 `data/tools/adb/`。
- **WebView2** 用户数据在 `cache/webview/`（`WEBVIEW2_USER_DATA_FOLDER`）。
- **更新包** 缓存在 `cache/update/`；覆盖安装成功后删除 setup。
- **拖出** 临时区在 `cache/drag-out/`。
- NSIS `PREINSTALL` 把 `$INSTDIR` 指到 Programs，并再 `SetOutPath`（Tauri 模板先 SetOutPath 再调钩子，`File` 跟 OutPath）。卸载勾选「删除应用数据」才清产品家园。

设置键与 adb 路径是本机的，不走 Roaming。

## 后果

覆盖安装不碰家园。完全卸载默认保留配置与命令库。关于页展示安装目录与缓存。
