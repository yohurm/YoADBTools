# ADR-v6-021 — 日志导出真相源

- **状态：** 已采纳（A：导出扫环）
- **日期：** 2026-08-28；修订 2026-09-07

## 背景

ADR-v6-006/007 规定：导出/回补永远基于 RingBuffer。中间曾落地 `SessionLogService`（采集中持续写已过滤行），与「仅用户导出时落盘」和环容量上限双轨并存。

## 决策

环是唯一日志行真相源。

- replay / 镜像回补：读环，不过滤；窗口过滤在 UI 消费端。
- 导出：`log.export` 带当前窗口 `from_seq` + `LogFilter`，core 用 `log_filter_matches` 扫环，写成一份 txt。受 `buffer_capacity` 约束。
- 采集过程不落盘。删除 session-logs 管道、`log.sessionFile*`、`log_write_mode`、`export_mode`。
- 复制与导出共用 `format_log_line`（domain + UI testdata）。

## 后果

长会话超出环容量的行不可导出。需要更长保留时提高 `buffer_capacity`。
