# ADR-v6-036 — 多格式文本解析引擎（`yohu-textparsing`）

- **状态：** 已接受
- **日期：** 2026-09-24
- **关联：** ADR-v6-034、ADR-v6-035、[modules/textparsing.md](../modules/textparsing.md)

## 背景

更新说明同时来自 GitHub REST Markdown、`releases.atom` HTML、XML 实体 / CDATA。把剥标签、解实体、去 Markdown 写进 `yohu-update::notes` 会把格式规则绑死在产品用例上，无法复用，也无法按来源声明格式。

## 决策

新增 **`yohu-textparsing`**，与 `yohu-search` / `yohu-download` 同级，**零产品类型、零 GitHub、零 Tauri**。

公开 API：

```rust
yohu_textparsing::to_plain(input, TextFormat::Html | Markdown | Plain)
yohu_textparsing::Html::to_plain / Markdown::to_plain / Plain::to_plain
yohu_textparsing::Xml::unwrap_cdata / Xml::decode_entities
yohu_textparsing::sniff_format   // 仅未知来源
```

`yohu-update` 按通道调用：Atom HTML → `TextFormat::Html`；REST / manifest notes → `TextFormat::Markdown`；Atom 元素文本先 `Xml` 再 Html。禁止在 update 内再写一套 HTML/Markdown 规则。

## 不做什么

- 不建 `yohu-foundation` 杂烩。
- 不做完整 CommonMark / HTML DOM；只收成设置页纯文本。
- 不把引擎放进 `yohu-domain` 或 `@yohu/api`。

## 验收

- `cargo test -p yohu-textparsing` 覆盖 Html / Markdown / Xml。
- `yohu-update` 无 `notes.rs` 内嵌解析器。
