# ADR-v6-041 — Linux 工作台

- **状态：** 已接受
- **日期：** 2026-10-09
- **补充：** [ADR-v6-029](ADR-v6-029.md)（多平台产品）、[ADR-v6-031](ADR-v6-031.md)（路径）、[ADR-v6-028](ADR-v6-028.md) / [ADR-v6-030](ADR-v6-030.md)、[ADR-v6-042](ADR-v6-042.md)（Linux 像素）

## 背景

029 把产品停在 Windows 与 macOS。Linux 上壳、路径和 sidecar 脚本已经能编过一部分，但安装根与数据根叠在一起，更新通道不认 `linux`，没有 WebKitGTK 依赖说明，也没有 CI。

投屏硬解仍然没有跨 OS 的原生 ABI。028 禁止用 FFmpeg 填 Linux 像素。

## 决策

1. **Linux 是工作台的交付平台。** 终端、文件、日志、设置可以构建并运行。窗口用系统 WebKitGTK 4.1（Tauri 2），不内嵌浏览器。
2. **路径继续分开。** 产品家园走 `$XDG_DATA_HOME/YohuAdbTools`，缺省 `~/.local/share/YohuAdbTools`。per-user 安装根是 `~/.local/opt/YohuAdbTools`，不跟数据根。`.deb` 把主程序装到 `/usr/bin`；关于页仍展示 per-user 安装根，与 Windows 不跟随当前进程路径同一口径。
3. **ADB 仍是官方 sidecar。** `scripts/setup-adb.sh` 拉 Linux platform-tools。解压到数据目录后补可执行位。sidecar 缺失时才查找 `ANDROID_HOME`、`ANDROID_SDK_ROOT`、`~/Android/Sdk/platform-tools` 和 `PATH`，避免两份 adb 抢 5037。
4. **更新认 `.deb`。** manifest 键 `linux-x86_64` / `linux-aarch64`。安装是 `xdg-open` 打开包，不静默覆盖。AppImage 可另打，不进更新通道。
5. **Linux 在 VLD 或可用的 OpenH264 二进制上出像素。** 拖出仍不交付。`probe().id` 仍是 `vaapi`，`hevc` 仍是 `false`。禁止 FFmpeg / libavcodec。见 [ADR-v6-042](ADR-v6-042.md)。
6. **USB 权限不在应用内提权。** udev 与 `plugdev` 由系统安装说明覆盖。

## 后果

- CI 增加 `ubuntu-latest` 的 Rust 与前端验证。发版标签仍以现有 Windows 流程为准，直到 Linux `.deb` 进入 GitHub Release。
- 主窗在 Linux 上记下 `GtkWindow` 指针。`spawn_surface` 按 [ADR-v6-042](ADR-v6-042.md) 画进它的 GDK 子窗口。拖出仍返回明确错误。
