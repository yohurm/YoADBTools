# ADR-v6-032 — 投屏呈现：几何 / 色彩 / 核 / 合成

- **状态：** 已接受（已落地：一次替换 `gpu.rs` 神文件职责）
- **日期：** 2026-09-15
- **补充：** [ADR-v6-024](ADR-v6-024.md)、[ADR-v6-026](ADR-v6-026.md)、[ADR-v6-027](ADR-v6-027.md)、[ADR-v6-028](ADR-v6-028.md)
- **调研：** YoAgentDocs `research/by-stack/client-runtime/` 呈现五层（libplacebo / mpv / moonlight / OBS / Magpie / zimg / libyuv / swscale / GStreamer / MiniEngine）

## 背景

声明栈：View → store → 类型化 IPC → commands → domain / `mirror_present`。不是 MVVM。

027 已锁：**占用 = contain dest**；内容尺寸来自 session；纹理可更大，blit 前裁源。清晰度核已否决 mip 与整数缩小 dest，热路径是面积平均。问题改到 **文件职责**：

`windows/gpu.rs` 同时持有 Video Processor 转色、内联面积 HLSL、viewport、DComp clip、swapchain Present。改核必须改 HWND/D3D 神文件。macOS `view.rs` 把缩小焊成 `kCAFilterLinear`。Fit（`scale.rs` / `Stage.dest`）已经独立，Convert / Scale / Compose / Present 没有。

十份源码同一分层：Fit 永不选核；Convert 永不改 dest；Scale 只吃已裁 RGB；Compose 不再 contain；Present 只翻页。

## 决策

1. **`mirror_present` 内五层，依赖单向。**

   ```text
   View → store → IPC → commands
     Stage          占用 / 模式 / chrome（OS 无关）
     Fit            present_dest(avail, content) → Letterbox
     Convert        YUV crop → RGB crop，1:1
     Scale          kernel(src_size, dest_size) → RGB dest
     Compose        DComp clip / NSView 卡片 = dest
     Present        swapchain / NSView contents
   ```

   Fit 不选核。核不改 dest 像素数。Convert 不缩放。Scale 看不到垫过的纹理。Compose 不再算 contain。下层不持有 View / store。

2. **Windows 落地边界（替换，不双轨）。**

   | 层 | 现状 | 目标 |
   |----|------|------|
   | Fit | `scale.rs` + `Stage.dest` | 保持 |
   | Convert | `gpu.rs` `vp_convert_native` | `windows/convert.rs`（或同等单职责文件）：只 VP + SourceRect |
   | Scale | `gpu.rs` 内联 `PS_RGB` | `windows/scale.rs` + 独立 HLSL/源字符串：只核 |
   | Compose | `gpu.rs` + `occupancy.rs` | clip / 描边只读 `Letterbox` |
   | Present | `gpu.rs` `present` | 只 ResizeBuffers / Present / 铬清屏调度 |

   `Gpu` 可以保留为装配门面，但 **禁止再内联核与 VP 实现**。门面不写几何、不写面积循环。

3. **macOS 同一五层。** NSView 铺满 avail；卡片 = dest。缩小核不得只设 `kCAFilterLinear` 了事；与 Windows 同一 `Letterbox`。实现可是 Metal/CoreImage 面积核，仍是 Scale 层。

4. **触控与截图。** 触控：dest → session 内容（已有 `map_client_to_video`）。截图：last NV12 / 内容尺寸，不经 Scale dest。

5. **一次替换。** 删除神文件里的核字符串与 VP 缩放分支。禁止保留 mip / 整数栅格 / 面积 三套运行时开关。禁止「先适配再删」。

## 设计前

```text
mirror.layout avail
  → Stage.dest = present_dest          # Fit 已独立
  → Host.place_occupancy / clip        # 与 dest 同盒
  → Gpu.present_gpu_nv12(dest)
        blit_texture_vp
          vp_convert_native            # Convert
          scale_native_to_dest
            draw_rgb + PS_RGB 内联     # Scale
        set_occupancy_clip             # Compose 仍在 Gpu
        swapchain.Present              # Present
```

问题：改 3×3 必须打开持交换链的文件；macOS 核在 view 滤镜；无法单独测 Scale。

## 设计后（已落地）

```text
mirror.layout avail
  → Stage.dest = present_dest                    # Fit：mirror_present/scale.rs
  → YuvConvert.yuv_to_rgb(crop)                  # Convert：windows/convert.rs；VP 1:1
  → RgbScale.draw(rgb, dest)                     # Scale：windows/scale.rs；HLSL 只在此
  → occupancy clip / chrome stroke(dest)         # Compose：windows/occupancy.rs + chrome.rs
  → Present.flip                                 # Present：windows/present.rs
触控 = map_client_to_video(dest, session)
截图 = Convert last NV12 @ 内容尺寸，不经 dest
```

`Gpu` 只装配。`gpu.rs` 不含 HLSL、不含 VP blit。核选择：`scale_kernel`（`scale.rs`）只喂 `Letterbox`。macOS 核在 `macos/scale.rs`，`view.rs` 不再焊死 `kCAFilterLinear`。

实现后（真机 NEPI4E0106，avail 1008×991，2026-09-15T01:44:24Z）：

```text
Live 1220×2712 h265 max_size=0
clip 446×991
投屏按源矩形面积缩小 crop=1220×2712 dest=446×991 nearest=false
texture 1248×2720 只被裁
```

## 否决

- 引入 libplacebo、FFmpeg/`libswscale`、zimg、MagpieFX、GStreamer、libyuv 进直播路径
- 为「清晰」砍 `max_size`、改 session 编码尺寸
- 整数缩小 dest、`GenerateMips`、VP 一次双线性压到 clip
- View 运行时 `containInZone` / CSS 占用
- OBS 式 `dest<src/2` 静默换低分双线性
- 双轨 API、兼容包装、`Gpu2`、注释冻结旧核
- 把这套叫做 MVVM / ViewModel

## 与 027 的关系

027 管 **占用卡片等于 contain dest** 与禁止 mip/整数 dest。032 管 **谁拥有核、谁拥有转色、谁拥有 clip**。dest 政策不变；变的是模块边界。
