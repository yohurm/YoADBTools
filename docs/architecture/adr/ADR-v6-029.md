# ADR-v6-029 — 多平台产品：Windows + macOS

- **状态：** 已接受
- **日期：** 2026-09-05
- **补充：** [ADR-v6-008](../README.md)（官方 ADB sidecar）、[ADR-v6-014](../README.md)（Windows NSIS）、[ADR-v6-024](ADR-v6-024.md) / [ADR-v6-028](ADR-v6-028.md)（投屏后端）、[ADR-v6-018](../文件拖拽-v6.md)（拖拽）

## 背景

v6 原目标只交付 Windows 10/11 x64。分层已经按 OS 无关 core + 编译期壳后端切开（028），但产品路径仍把 Windows 细节写进契约：`adb.exe` 三件套、NSIS、WebView2、HWND/DComp、自定义右上角三键。

要在 Mac 上跑通工作台（设备 / 终端 / 文件 / 日志），必须把「官方工具链」和「窗体铬层」从 Windows 文件名里抽出来，同时保持 Windows 行为不变。

## 决策

1. **产品目标改为 Windows x64 + macOS（Apple Silicon / Intel）。** Linux 仍不交付。投屏像素在 macOS 走 VideoToolbox（[ADR-v6-030](ADR-v6-030.md)）；禁止用 FFmpeg 填坑。
2. **ADB sidecar 跟平台走官方 platform-tools。** Windows：`adb.exe` + `AdbWinApi.dll` + `AdbWinUsbApi.dll`。Unix：`adb`。解析、解压、bundle resources、集成测试一律用 `yohu_adb::adb_file_name()` / `ADB_FILES`，禁止再写死 `adb.exe`。
3. **打包分平台配置。** 公共 `tauri.conf.json` 只放身份、窗口下限、`scrcpy-server`。Windows 覆盖：NSIS + WebView2 bootstrapper + Win adb 三件套。macOS 覆盖：`app`/`dmg` + `adb` + Overlay 标题栏 + USB/JIT entitlements。WebView：Windows = WebView2，macOS = 系统 WKWebView。
4. **窗体铬层跟 OS 习惯。** Windows 保持 `decorations: false` + 自定义右上角三键。macOS 用 `titleBarStyle: Overlay` + 系统交通灯；UI `nativeCaptions` 隐藏自定义三键，左侧 token `--yohu-layout-titlebar-traffic` 让位。
5. **更新。** 检查/下载仍走 GitHub Releases，按 `PlatformInfo.os/arch` 选包（Windows `*-setup.exe`，macOS `*.dmg`）。Windows 覆盖安装仍是 NSIS `/S` 后退出。macOS 打开 DMG，由用户拖入 `/Applications`，进程不退出。
6. **拖出。** Windows 仍是 OLE `GetData` 才 pull。macOS 先 pull 到会话目录再 `NSDraggingSession` 提供文件 URL（ADR-v6-030）。Linux 返回明确错误。
7. **数据根已由 `yohu-runtime::os_paths` 分 OS。** macOS = `~/Library/Application Support/YohuAdbTools/`。`system.info.os` 把编译目标 OS 交给 UI（设置页过滤、标题栏）。

## 管道

```text
官方 platform-tools（win.zip / darwin.zip）
  → tools/adb(.exe) sidecar
  → ToolResolver（用户路径 → 资源目录 → DataRoot/tools/adb）
  → AdbClient / 采集 / 文件 / 投屏控制面     ← 全平台同一 crate

投屏画面
  → yohu-mirror FramePipe                   ← 全平台
  → 壳 PresentHost（编译期）
       Windows : MF + HWND + DComp
       macOS   : VideoToolbox + NSView（ADR-v6-030）
       Linux   : 预留
```

## 否决

用 Windows `adb.exe` 在 Mac 上跑、用 FFmpeg 当 macOS 投屏、把 NSIS `/S` 硬套到 DMG、在 Mac 上画一套假交通灯、为跨平台把 Windows Present 改成虚函数热路径。

## 后果

- 新机器：Windows 跑 `scripts/setup-adb.ps1`；macOS/Linux 跑 `scripts/setup-adb.sh`。scrcpy-server 同样有 `.ps1` / `.sh`。
- CI 在 `windows-latest` 继续做完整验证与 NSIS；`macos-latest` 跑 Rust + 前端验证。发版标签同时挂 NSIS 与 DMG。
- 投屏在 Mac 上走 VideoToolbox，舞台空态/加载/画面与 Windows 同一套 `Stage`。Linux 可编译、无画面。
