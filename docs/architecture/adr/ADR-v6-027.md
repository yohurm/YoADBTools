# ADR-v6-027 — 投屏占用：舞台透明洞 + HWND 占用卡片

- **状态：** 已接受
- **日期：** 2026-09-04
- **补充：** [ADR-v6-024](ADR-v6-024.md)、[ADR-v6-026](ADR-v6-026.md)

## 背景

声明栈：View → store → typed IPC → commands → shell present。

026 把舞台像素交给 HWND 之后，占用一度在 UI 算：`containInZone` 写出 hug 盒，YoPanel 铺满 hug 框，`mirror.layout` 报插值后的视觉盒。CSS 占用宽高过渡与 HWND 跟框锁步会左右跳。

随后两版都被实机否决：

1. **HWND 铺满整列舞台 YoPanel、画面只在 HWND 内 letterbox**：抖动消失，但左右边框是 YoPanel 外框，不再贴合画面。
2. **舞台 YoPanel 铺满列 + HWND 在面板内 contain**：avail 稳定，HWND 确实变窄，但用户看见的左右边框仍是 YoPanel，占用卡片看起来没变。

面板内全屏被做成 `position: fixed; inset: 0`。页眉被盖住。`SetFullscreenState` 非法。

## 决策

1. **View 只报稳定 avail。** 可用区 = 舞台列 `.yohu-mirror__avail`（透明洞，不是 YoPanel）。`mirror.layout` 报该格子相对主窗客户区的物理矩形 + 会话旗标。禁止报 contain 目标，禁止 `video_width` / `stroke_px`，禁止 CSS 占用宽高过渡。
2. **舞台不是 YoPanel。** 内容区只有操作栏 / 质量是 `YoPanel`。舞台列是布局槽：WebView 透明，露出 `--yohu-canvas`。可见占用卡片是 HWND。
3. **HWND 是稳定合成目标，可见卡片是 DComp clip。** `CreateTargetForHwnd` 把合成树裁在窗口可见区（[CreateTargetForHwnd](https://learn.microsoft.com/en-us/windows/win32/api/dcomp/nf-dcomp-idcompositiondevice-createtargetforhwnd)）。官方初始化把 Visual `SetOffsetX/Y` 相对目标窗口，不靠 `SetWindowPos` 跟布局（[Initialize DirectComposition](https://learn.microsoft.com/en-us/windows/win32/directcomp/initialize-directcomposition)）。`SetWindowPos` 与 `IDCompositionRectangleClip::Commit` 是两条合成事务，不能把「槽 HWND + clip.left=dest.x」当成一张卡片，也不能让 HWND 矩形跟 CSS 侧栏弹簧每帧走。Windows：HWND 铺满主窗客户区；交换链与 HWND 同尺寸。Fill / idle / failed / unbound：clip 与铬 = avail（主窗客户区坐标）。Dest：clip 与 Present dest = contain（同一坐标系）。avail 物理矩形先取整四边再导出宽高。侧栏只改 clip 与回缓冲；禁止 `SetWindowPos`。编码尺寸只来自 FramePipe；`stop` 保留上次尺寸。
4. **HWND 画占用铬层。** surface / hairline：描边画在占用盒上。卡片外回缓冲预乘透明，露出 WebView。圆角仍在 DComp clip。占用 Fill→Dest 走 **IDCompositionAnimation** + `MotionSpec::SpatialPanel`（300ms 标准）；Dest→Fill（停止后空态铺满 avail）走 `SpatialEnter`（350ms 减速）。铬与 clip 同一规格采样。禁止 CSS 占用宽高过渡、禁止运行时 UI `containInZone`、禁止 hide-on-jump 48px、禁止用 `SetWindowPos` 冒充 fill↔dest 或侧栏跟框（`CreateSwapChainForComposition` 强制 `DXGI_SCALING_STRETCH`）。禁止 GenerateMips 当缩小器；禁止把 dest 收成整数分数换「清晰」。缩小用对准 dest 的面积核。
5. **面板内全屏是布局。** 只藏操作栏与功能栏。禁止 `position: fixed; inset: 0`。禁止 DXGI exclusive。

## 否决

WebView2 composition visual hosting、独立 scrcpy 窗、DXGI exclusive fullscreen、CSS 占用宽高过渡、UI 运行时 `containInZone`、`layout.video_width`、hide-on-jump、用舞台 YoPanel 当可见左右边框、用 `SetWindowPos` 每帧改 HWND / DXGI stretch 上一帧冒充占用动效或侧栏跟框。

## 设计前 / 设计后（侧栏占用）

设计前：

```text
UI rAF 报 avail（侧栏 200↔48 弹簧）
  → Stage 把 HWND 矩形写成 avail 或 dest
  → GeomHost.SetWindowPos + DComp clip.Commit
  → DXGI_STRETCH / ResizeBuffers
```

问题：USER32 与 DComp 两条合成事务；空态/卡片 HWND 尺寸跟 CSS 插值走，右边框和中间内容抖。

设计后：

```text
UI rAF 报 avail
  → Stage dest/occupancy = 主窗客户区坐标（Fill=avail，Dest=contain）
  → 只 Commit DComp clip + 在稳定交换链上重画占用盒
HWND SetWindowPos / ResizeBuffers 只跟主窗客户区
```
