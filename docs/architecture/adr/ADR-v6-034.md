# ADR-v6-034 — HTTP 文件下载原语（`yohu-download`）

- **状态：** 已接受
- **日期：** 2026-09-24
- **关联：** ADR-v6-022（应用更新通道）、[layers.md](../layers.md)、YoAgentDocs `rule.common.architecture` / `stack-layering`（View → store → IPC → domain）

## 背景

`yohu-update` 曾同时承担 GitHub Release 语义与 HTTP 流式落盘（reqwest、`.part`、SHA-256、超时）。违反单一职责：传输重试/进度与「选包、缓存路径、NSIS 覆盖」耦合，且无法在其它 HTTP 落盘场景复用。

## 决策

1. 新增 **`yohu-download`**，与 `yohu-runtime ∥ yohu-protocol ∥ yohu-motion ∥ yohu-search` 同级，**零产品 wire 类型、零 GitHub、零 adb、零 Tauri**。
2. **`yohu-update`** 只做产品「应用更新」用例：检查、Release 解析、说明格式化、安装包缓存约定、覆盖安装；**下载字节**只通过 `yohu-download` 公开 API。
3. **鉴权与 GitHub 主机策略**留在 `yohu-update`（`url_policy`）；调用下载前组装 `DownloadSpec.headers`（含可选 Bearer），下载引擎不识别 GitHub。
4. **进度与错误模型分层：**
   - `yohu-download`：`DownloadProgress { received, total, phase }`、`DownloadError`
   - `yohu-protocol`：`UpdateProgress` / `UpdateStage`（IPC）
   - `yohu-update`：映射 download → update 进度；`update_runs`（壳）映射 → `AppEvent::UpdateProgress`
5. 下载引擎提供：**`.part` 写盘、流式 SHA-256、取消、可配置重试与退避**（单次 attempt 失败可整包重试；Range 续传为后续增强，不阻塞本 ADR）。
6. 禁止在 `app/yohu-adbtools` 或 UI 引入 reqwest / 下载实现；禁止 `yohu-download` 依赖 `yohu-update` 或 `yohu-protocol`（保持原语独立）。

## 依赖

```text
yohu-download →（reqwest, tokio, sha2, …）  // 不依赖 protocol / runtime / update
yohu-update   → yohu-download + yohu-protocol + yohu-runtime
```

## 不做什么

- 不把 HTTP 下载并入 `yohu-files`（设备传输走 adb，非 HTTP）。
- 不在 `yohu-runtime` 加 HTTP（runtime 保持零网络）。
- 不保留 `yohu-update` 内第二套 reqwest 客户端（迁移后删除旧 `download.rs` 实现）。

## 验收

- `cargo test -p yohu-download` 覆盖 URL 策略、本地 HTTP 夹具、重试分类。
- `cargo test -p yohu-update` 保留 GitHub 头策略与 `download_configured` 集成夹具（经 `yohu-download`）。
- `layers.md` / `modules/download.md` / `modules/update.md` 与 as-built 一致。
