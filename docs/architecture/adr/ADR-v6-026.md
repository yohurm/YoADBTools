# ADR-v6-026 — 投屏舞台像素所有权

- **状态：** 已接受
- **日期：** 2026-09-03
- **补充：** [ADR-v6-024](ADR-v6-024.md)（Windows：进程内 MF + HWND）、[ADR-v6-028](ADR-v6-028.md)

## 背景

024 把视频放在主窗 `WS_CHILD` + `WS_EX_NOREDIRECTIONBITMAP` + DirectComposition 交换链上，帧不进 JS。空态/加载仍画在 WebView overlay 里，并用 `painted()` 与 HWND **XOR**：出画卸掉 overlay，停止再拆 HWND、指望 WebView 把空态画回来。

这两层抢同一块客户区。NOREDIRECTIONBITMAP 子窗由 DWM 单独合成，不进入 WebView backing。`DestroyWindow` / `SW_HIDE` 之后 WebView2 往往不再栅格化曾被挡住的矩形，内容面板变白板。首次进入从未创建 HWND，所以空态看起来正常。在 JS 里重挂 overlay 或延时 invalidate 解决不了所有权。

编码停止（`mirror.stop`、`mirror/state=stopped`）还被误绑成拆 HWND（`PresentHost::detach` → `Cmd::Stop` → `DestroyWindow`），把控制面会话和舞台表面当成同一个对象。

## 决策

1. **舞台像素只由 HWND 持有。** 投屏页可用区可见且 ≥64px 时创建表面；空态 / 加载 / 暂停 / 视频都画在这块表面上。WebView 只留透明占位上报几何，不再画舞台内容。
2. **两段生命周期。** HWND ↔ 当前模块是否为投屏（工作台 `mirror.present.setActive`；进页 `true` 后 `mirror.layout` 建表面，离页同一拍 `false` 并 `shutdown`）。解码管道 ↔ `mirror.start` / `mirror.stop`（`BindPipe` / `UnbindPipe`）。停止投屏只解绑管道并改画 chrome，禁止拆窗。未激活时丢弃一切 layout。进出投屏页的 View 挂载跟模块身份同一拍，禁止等 Presence `onExitComplete`。重建表面先 `Layout` 再 `BindPipe`。禁止页面 Presence / CSS 推断 HWND。
3. **铬层文案与颜色在壳。** 空态 / 加载 / 暂停由 HWND Direct2D/DirectWrite 绘制。产品文案与色值在壳内，不经 `mirror.layout` 传 title / ARGB。UI 只报 avail 与会话旗标（含 `dark` / `failed` / `error` / `has_device`）。`dark` 跟工作台 `data-theme`；设备夜览只走月亮钮。
4. **几何。** 占用见 [ADR-v6-027](ADR-v6-027.md)。`mirror.layout` 报舞台列 `.yohu-mirror__avail` 客户区物理矩形 + 会话旗标。Windows：HWND 铺满主窗客户区；可见卡片是 DComp clip（idle / failed / unbound = avail；Dest = contain）。Fill↔Dest 只插值 clip。编码尺寸不来自 UI；present 在 `stop` 后保留上次尺寸。占用 fill↔dest 走 `IDCompositionAnimation`；缩小用面积核，禁止 GenerateMips 与整数缩小 dest。主窗改尺寸瞬时跟 HWND。禁止 UI 运行时 `containInZone`、禁止 CSS 占用宽高过渡、禁止 `video_width` / `stroke_px`。HWND 创建即 `WS_DISABLED`（禁止 `EnableWindow(true)`），`WindowFromPoint` 跳过 disabled，不靠跨线程 `HTTRANSPARENT`。侧栏只改 clip 与绘制；主窗客户区变了才 `SetWindowPos` / `ResizeBuffers`。离开投屏页拆 HWND 时对主窗 `InvalidateRect`。
5. **显示与命中。** 几何宿主在放下 Host 锁之后才 `SetWindowPos`（禁止持锁跨调用；禁止 `SWP_NOCOPYBITS`）。`SetWindowPos` 只用于 HWND 铺满主窗客户区。主窗改尺寸：owner subclass 跨线程 `SWP_ASYNCWINDOWPOS`。`ShowWindow` 只在 chrome 或视频 Present 成功之后，避免空 DComp 交换链先闪一帧。卡片外像素预乘透明。HWND 在呈现线程创建，只合成不命中：创建即 `WS_DISABLED`。`WindowFromPoint` 跳过 disabled，UI 线程不会对呈现线程 `SendMessage(WM_NCHITTEST)`。操作指针由 `.yohu-mirror__avail` 以与 layout 同一套主窗客户区物理坐标走 `mirror.pointer`，Stage `dest()` 映射后注入。**呈现线程锁边界：** `wndproc` 不锁 Host；`ResizeBuffers` / DComp `Commit` / DXGI `Present` / `ShowWindow` / `SetWindowPos` 均在 Host 锁外。`Mutex<Host>` 不能重入，USER32/DXGI 会同步派消息。
6. **否决。** 出画期间卸 overlay、停止后再请 WebView 接管；用 timeout/`InvalidateRect` 当产品行为；WebView2 `Bounds` 挖洞（单矩形盖不住中间舞台）；为 chrome 再开一个 WebView。

## 后果

`PresentHost` 主窗至多一块舞台。`detach` 语义改为 unbind。IPC 见 `ipc.md`；呈现见 `modules/mirror.md`。
