# ADR-v6-039 — 命令库默认展开

- **状态：** 已接受
- **日期：** 2026-10-07
- **关联：** ADR-v6-009、[modules/terminal.md](../modules/terminal.md)、[ipc.md](../ipc.md)

## 背景

命令库树在挂载时把每个命令组都展开。组一多，左栏只剩目录，叶子要逐组收起才能扫。需要一项设置：默认全部折叠或全部展开，并能指定默认展开哪些命令组。本应用默认全部折叠。

手动开合是这一次停留里的事。把它写进设置，会让每次点击都变成一次 `settings.set`。组名会改、会导入，用名称当身份会对不上。

## 决策

1. **一个设置键** `terminal_library_expand`，立即生效。不另立布尔再加一份名单。形状：

   ```json
   { "mode": "collapsed", "ids": [] }
   ```

   `mode` 为 `collapsed`（全部折叠）、`expanded`（全部展开）或 `groups`（只展开 `ids`）。缺字段回落 `{ "mode": "collapsed", "ids": [] }`。产品默认全部折叠。

2. **`ids` 是命令组 id。** 不存组名，不存树键 `g:`。改名不影响展开。`collapsed` 与 `expanded` 不看 `ids`，但写入时保留名单，切回「指定命令组」时勾选还在。`groups` 且名单为空，视觉上等于折叠。库里没有的 id 留在设置里，组重新出现后仍展开。domain 不读命令库，不按库剔除。校验在 `apply_setting`：去掉首尾空白、拒绝空串、每个至多 128 字、列表至多 256 个、重复去掉并保留先出现的顺序。

3. **停留开合不写回设置。** 终端 `LibraryPane` 持有本次停留的开合集。策略变化（含 `ids`）按策略重铺。库成员变化时：还在的组保留手动开合；新组按策略补上；消失的组丢掉。检索有关键词时，可见组强制展开，且不写入停留集；清空检索回到停留集。命令管理三栏不是这棵树，不套用。

4. **投影与界面。** 哪些组 id 该开，在 `@yohu/api` `libraryExpandGroupIds`。停留对账在终端模块。设置页在命令终端分组：主项是模式下拉（全部折叠 / 全部展开 / 指定命令组）。「指定命令组」是这一行的子项（caption 标题 + 组勾选），不是并列主行；子项开闭高度走 `YoCollapse`。模式为指定组时，用已有 `commandlib.load` 取组名做勾选。设置页不 import 终端模块。`YoTree` 受控展开增加 `onToggle`：有回调则把开合交回调用方；没有回调时受控树不改本地状态。检索进行时回调直接返回，不改停留集，可见组仍强制展开。进终端页时，已应展开的组由折叠从 0fr 过渡到内容高。

## 不做什么

- 不把每次点击写入设置。
- 不按组名匹配。
- 不让检索改写停留开合。
- 不改命令管理三栏，不新增 invoke。

## 验收

- `cargo test -p yohu-protocol --lib settings`：缺字段回落折叠；模式蛇形。
- `cargo test -p yohu-domain --lib settings`：折叠为默认；非法模式与空 id 拒绝；重复 id 去掉。
- `@yohu/api` `library-expand`：三种模式的投影；切模式保留 ids。
- 终端 `library-expand`：策略变化重铺；新组按策略补；手动开合在策略不变时保留。
- 设置页：默认「全部折叠」；切到指定组并勾选一组，写入整份 `{ mode, ids }`。
