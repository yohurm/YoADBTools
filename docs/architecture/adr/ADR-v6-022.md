## 决策

更新检查与覆盖安装在 core crate `yohu-update`：固定查询 `yohurm/Windows-YoADBTools` 的 GitHub Releases。不引入 `tauri-plugin-updater`。设置页不提供更新源切换。

壳命令：`update.check` / `info` / `download` / `install` / `cancel` / `open`。进度事件 `update/progress`。仓库覆盖走环境变量或 `config/update.json`。密钥不进 `settings.json` 主表，也不打进安装包。

覆盖安装对照：

- **Tauri plugin-updater**：NSIS 用 `/S /UPDATE`（跳过「先卸载」）；`/NS` 避免静默升级刷桌面快捷方式。不加 `/R`，由助手校验主程序后再拉起，避免双启动。
- **VS Code User**：安装根在 `%LOCALAPPDATA%\Programs\…`；安装包不进安装根；先退出再写文件。
- **Omaha**：setup 失败（文件锁）指数退避重试，结果落日志。

流程：安装包下到产品家园 `cache/update/` → Windows 助手脱离作业对象，等 PID 退出并 settle → `/S /UPDATE /NS`（最多 4 次）→ 成功后删 setup、拉起 `Programs\YohuAdbTools.exe`；失败保留 setup，写 `apply.log`。macOS 打开 DMG，进程不退出。配置/日志/数据不随安装包覆盖。

`yohu-update` 可依赖 `yohu-protocol` 与 `yohu-runtime`（persist / os_paths），**禁止**依赖 `yohu-adb` 与 Tauri。
