# ADR-v6-033 — 文件浏览：能力会话（对齐 Android FileListing）

- **状态：** 已接受
- **日期：** 2026-09-23
- **补充：** [ADR-v6-008](README.md)（官方 ADB sidecar，不重实现协议）、[ADR-v6-013](README.md)（SafetyRoot）、[ADR-v6-016](README.md)（采集槽位）、[ADR-v6-025](ADR-v6-025.md)（目录 ≠ 运行时）、[modules/files.md](../modules/files.md)

## 背景

进目录的产品路径曾是 `files.list` → `FileBrowser.list` → `AdbClient::browse_list`。脚本已把祖先 `readlink -f` 与 `ls -lla` 合成一次设备侧执行（安全根不得因「进过父目录」而跳过）。运输曾是每次 `ProcessRunner.run_capture`：新起 `adb.exe`、连 server、设备上新开 shell、跑完退出。

USB 上小目录常见 100–400ms，大头是进程与 shell 启动，不是解析、不是虚表、也不是 UI 快照。UI `dirCache` 只让回访立刻出旧行，**不能**让第一次打开没进过的目录变快，也不能代替 core 复核。

曾把长驻 `adb shell -T` 藏进 `AdbClient::browse_list`，再用 `retain_browse` 跟 Hub 的 Online 集合对齐。寿命说不清（Online / 第一次 list / 掉线），`AdbClient` 不再是「短命令 + 解析」，与 016/025 两套叙事。

### Android 分层（对齐策略，不克隆协议）

AOSP：Client → Server(5037 复用) → Transport → adbd。Android Studio 是第二个 ADB client（ddmlib `AdbHelper` / adblib `AdbSession`），每次 list 仍是一条新本地流 `host:transport:<serial>` 再 `shell:ls -l <path>/`。设备上每次新开 `shell:`，宿主**不**新起 CLI 进程。ADR-v6-008 禁止重实现这条 host 协议。

| Android | Yohu |
|---------|------|
| `AdbSession` / Bridge | 官方 adb sidecar + `AdbClient` 短命令 |
| `createDeviceScope`（掉线 cancel） | went_offline（壳目录，不是 IPC）：browse_runs.replace + FileBrowser.detach(serial) 与 replace 同一拍强制关当时槽，不得把无世代 detach 接在采集 join 之后。采集 / 投屏后台收敛 |
| Device Explorer 工具窗 | `FileView` `attachView` / `detachView` |
| `FileListingService` | `yohu-files` 浏览会话（Empty / Starting / Live + generation） |
| `FileEntry` 缓存 | `listing.ts` `dirCache`（只绘制；每次仍 list） |
| `AdbFileOperations` | `FileMutator` |
| `sync:` LIST/SEND/RECV | `TransferRunner`（push/pull；不用 LIST 当清单） |
| AdbHelper 每趟 `shell:` 新流 | `DeviceShell`：一条 sidecar `shell -T` 上多趟 `exec`（008 补偿，不是 AS 功能） |

不抄：不当 5037 第二客户端；不 `useCache` 跳过 ls（SafetyRoot + 目录可被换成符号链接）；不把 FileListing 焊进 Hub；不实现 `run-as` / 全盘 `/data`；不把 AS 的 ls 排队改掉「后一次取消前一次」。

## 决策

1. **浏览是能力会话，与采集 / 投屏同构。** 每 serial 至多一路 Empty / Starting / Live，寿命与 **generation** 在 `yohu-files`（对标 ADR-v6-016 CaptureStart：后续操作针对世代，不是 attach 后再无世代 list）。`files.session.attach(serial)` 返回 BrowseAttach { serial, generation, adopted }：Empty→Starting（分配世代）→握手→Live；已 Live 则 adopt。握手期间 **不** 握槽位锁。过期 attach 不得把更新一代写成 Live。attach Ok 表示该世代在槽位提交时已发布 Live；不表示稍后一次 IPC 观察时槽位仍 Live。files.list(serial, path, generation)：无槽 / Closed → NotAttached；世代不符 → Cancelled；Starting 且同世代则等待；Live 且同世代才 list。后一次取消前一次。永不在 list 里偷偷 attach。files.session.detach(serial, generation) 走 browse_runs::release：世代不符空操作（不关槽、不 replace 取消在途 list，不得杀掉更新 Live）；命中才关槽并取消在途 list。UI 持有 `BrowseAttach.generation`。went_offline（壳目录，不是 IPC）：browse_runs.replace + FileBrowser.detach(serial) 与 replace 同一拍强制关当时槽，不得把无世代 detach 接在采集 join 之后。视图卸载 / `bindSerial(null)` 带所持世代。改 `adb.path`：`drop_workers`、槽位仍 Live、世代不变；下一趟 list 再握手。exec 失败杀工人、槽位仍 Live，下一趟再 open。握手 `Unsupported`（无 `-T` 或 非 sh / 从未打印 `__YOHU_SHELL_READY__`）才记 oneshot；Timeout / Cancelled / DeviceOffline 不记 oneshot。files.dragOut / FileBrowser.list_tree(serial, remotes, generation)携带 BrowseAttach.generation；禁止 peek 槽位世代。
2. **`DeviceShell` 是 008 补偿层，不是 FileListing。** 宿主命令 `adb -s <serial> shell -T`（stdin/stdout/stderr 全管道；`-T` 禁止 PTY）。握手：清 `PS1`/`PS2`，打印 `__YOHU_SHELL_READY__`。stdout EOF 或握手失败须先排空 stderr 再分类：offline 针优先 → 选项拒绝（unknown / unrecognized / invalid option，即宿主拒 `-T`）→ 握手不可用（非 sh / 从未打印 `__YOHU_SHELL_READY__`）则 `Unsupported`。Timeout / Cancelled / DeviceOffline 保持原类，不升格 `Unsupported`。Live 之后 exec 断管若无上述 stderr 类，保持 `Failed`（杀工人、槽位仍 Live，下一趟 list 再 open）。`exec` 把脚本包进子 shell（`exit` 不得打死会话），前后打 `__YOHU_BEGIN_<n>__` / `__YOHU_END_<n>__ <code>`。短命令信号量不占这条会话。`AdbClient` 只留短命令门面（`run` / `ls` / `readlink_f` / Hub）与 `open_device_shell`；禁止在 `browse_list` 里藏池。
3. **工具窗挂载才开 FileListing，插上设备本身不开。** `FileView` 挂载且有 serial = attach → BrowseAttach { serial, generation, adopted } → 持有 `BrowseAttach.generation` → files.list(serial, path, generation)。attach Ok 表示该世代在槽位提交时已发布 Live；不表示稍后一次 IPC 观察时槽位仍 Live。files.list(serial, path, generation)：无槽 / Closed → NotAttached；世代不符 → Cancelled；Starting 且同世代则等待；Live 且同世代才 list。后一次取消前一次。永不在 list 里偷偷 attach。离开模块 / `bindSerial(null)`：files.session.detach(serial, generation) 走 browse_runs::release：世代不符空操作（不关槽、不 replace 取消在途 list，不得杀掉更新 Live）；命中才关槽并取消在途 list。检测到 Online 只进目录 / Hub。第一次进模块付 spawn+list；之后进子目录只 `exec`。握手 `Unsupported`（无 `-T` 或 非 sh / 从未打印 `__YOHU_SHELL_READY__`）才记 oneshot；Timeout / Cancelled / DeviceOffline 不记 oneshot。该 serial 回退 `adb shell sh -c` 短命令（oneshot），行为与改前相同。取消 / 超时 / 断管：杀掉工人，槽位仍 Live，下一趟再 open。
4. **禁止** 用 UI 快照代替 list；禁止因进过父目录跳过 `readlink`；禁止自写 `sync:` / host 协议；禁止把 logcat / 状态采样 / 传输接到 `DeviceShell`。

## 非目标

- 不把 SYNC LIST 当清单源。
- 不在浏览 shell 上复用 Hub 的 dumpsys 脚本。
- 不在检测到 Online 时预热浏览。
- 不做悬停预取（`browse_runs` 单槽；预取会取消当前对账）。
- 不把大目录改成流式首屏（排序与现 IPC 仍是整表）。
- 不抄 `run-as`、不抄 AS 5s `useCache` 跳命令、不抄 `mThreadList` 排队。

## 后果

回访仍然可以立刻画快照；进入文件管理之后再进子目录不再付第二次 `adb.exe` spawn。列语义、mtime、安全根不变。`files.list` / `files.session.detach` 携带 generation（对标 CaptureStart）。files.dragOut / FileBrowser.list_tree(serial, remotes, generation)携带 BrowseAttach.generation；禁止 peek 槽位世代。用户停在终端/日志/投屏时不占浏览 shell。IPC：`files.session.attach` → BrowseAttach { serial, generation, adopted } → 持有 generation → files.list(serial, path, generation)。attach Ok 表示该世代在槽位提交时已发布 Live；不表示稍后一次 IPC 观察时槽位仍 Live。files.list(serial, path, generation)：无槽 / Closed → NotAttached；世代不符 → Cancelled；Starting 且同世代则等待；Live 且同世代才 list。后一次取消前一次。永不在 list 里偷偷 attach。files.session.detach(serial, generation) 走 browse_runs::release：世代不符空操作（不关槽、不 replace 取消在途 list，不得杀掉更新 Live）；命中才关槽并取消在途 list。went_offline（壳目录，不是 IPC）：browse_runs.replace + FileBrowser.detach(serial) 与 replace 同一拍强制关当时槽，不得把无世代 detach 接在采集 join 之后。
