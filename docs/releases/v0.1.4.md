# Yohu ADB Tools v0.1.4

> 补丁版本升级：Linux 平台正式交付 + 三端安装包，日志模块数据面重构（IPC 契约有变更）。

## 亮点

- **Linux 正式交付**：工作台可在 Linux 构建运行，产出 `.deb`；投屏有硬解走 VA-API，没有时用按需下载的 Cisco OpenH264 软解出画。
- **三端安装包一次发布**：Windows NSIS / macOS DMG / Linux deb 并行打包，汇总多平台 `update-manifest.json`，应用内检查更新可直接使用。
- **日志模块重塑**：数据面视口化，`log.query` 在 core 侧过滤分页，UI 每个窗口只持视口（≤2000 行），内存不再随缓冲容量线性放大；实时取数改为「水位信号 + 按 seq 拉取」。

## 新增

- Linux 工作台与 `.deb` 安装包（WebKitGTK 4.1、XDG 路径、安装根/产品家园分离）。
- Linux 投屏：VA-API 硬解或 OpenH264 私有软解，画进 GTK 子窗口；OpenH264 由用户在设置里点击下载（二进制不进安装包，校验 SHA-256）。
- 关于页两行：安装根 / 本次程序分列，新增「下载 OpenH264」。
- 日志默认环形缓冲提升到 **100000** 行；窗口按环容量保住过滤后文档；行号滚轴。
- 文件：同目录换名先问占用；预览栏改为折叠列向轴。
- 终端 / YoUI：命令管理行留白与菜单井对齐，容器色彩表与特殊铬统一。

## 改进与重构

- **ADR-v6-050** 日志数据面视口化：新增 `log.query`（forward/backward + `has_more`）；删除 UI 全量文档与三份正文路径。
- **ADR-v6-049** 实时取数：`log/appended` 只报水位，UI 用 `log.range` 按 seq 拉取；移除 `log/hits` 正文、`log.window.bind/release`、`LogOverflow`。
- **ADR-v6-048** 连续 seq 游标 + 单一对账原语 + 空洞自愈，删除 `bumpPage/pageGen` 双代际。
- **ADR-v6-047** 采集槽位 / 跟流 / 窗口索引 / 环容量状态机闭合，单一数据源。
- **ADR-v6-046** 日志解耦；修复 Tag 含 `/` 的解析缺陷。
- 设置 `clear_device_on_start` 默认恢复 `true`。

## 性能

- 环读取 O(1) 下标化、`Arc<str>`、列式二进制 IPC、批量提交；修复实时拉取风暴卡死。
- 真机压测：单设备尾窗/头页 200 行约 7–8ms；3 设备并行 8–10ms。

## 修复

- 修复 Tag 含 `/`（如 `I/OkHttp/4.9.0`）时整条日志丢失、下一条时间戳卡在上一条尾部。
- 修复带过滤窗口把命中 seq 间隔误判为空洞。
- 修复日志任务账本原子性、错误分类与 UI 状态机收口。
- 修复 Linux 投屏舞台铬/占用卡片与 Windows 不一致。
- 修复文件列表失败态与 Linux 投屏绑定失败的画面洞。
- 修复 NSIS 安装包图标不显示。
- 修复 macOS / Windows 误编 Linux 呈现档、三端 CI 事实不一致。

## 升级注意

- **IPC 契约变化**：`log/hits`、`log.window.bind`、`log.window.release` 已移除，改用 `log/appended` + `log.query` / `log.range`；自建调用方需同步。
- **Linux 投屏**：先在设置里下载 OpenH264（不打进 `.deb`）。
- **macOS**：安装包未签名，首次打开需在「隐私与安全性」允许。
