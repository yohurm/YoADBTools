# Linux 功能核对清单

对照产品表面，不是冒烟。验证机是本仓库已安装的 Linux 工作台，设备用已完成首启的 AVD（`yohu_atd34`，`emulator-5554`，`sys.boot_completed=1`，`/storage/self/primary` 存在）。未完成首启的 `google_apis` 镜像不能当文件或投屏的通过条件。

「已知缺口」只记已经在这台 VM + ATD 上看到的事实，或 ADR 写明本期不做的事。没测过的写「未测」。

## 投屏

控制面板和舞台不是一件事。会话 `Live` 只说明 scrcpy 隧道和编码尺寸到了。像素在壳内表面。Linux 表面是 `spawn_unimplemented("vaapi")`，不解码、不画铬。

| 项 | 期望 | 怎么核对 | 已知缺口 |
|----|------|----------|----------|
| 未开始 | 舞台写「未开始 / 点击开始将画面嵌在此面板内」。开始可点（已选设备） | 选中 ATD，打开投屏，不点开始 | **舞台没有这句。** 洞是透明的，看到的是页面底色。开始钮本身可用 |
| 开始 | 钮变「停止」并进入加载。失败时舞台「启动失败」加原因（例如「等待设备连接超时」） | 点开始，看钮、状态栏任务「投屏: emulator-5554」、舞台文案 | 已启动的 ATD：约 16s 进入 Live，钮变停止，任务在。失败句只进 `mirror/state` 和 layout 旗标，**面板不 Toast，舞台不画**。未完成首启时 15s 超时，舞台同样是一块灰 |
| 分辨率徽章 | Live 且宽高 > 0 时状态栏出 `宽×高`；画出帧之后才加 fps | 看状态栏 | ATD 上会出 `720×1280`，**没有 fps**。`mirror/painted` 不会来 |
| 暂停 / 面板内全屏 | Live 后可点。暂停舞台写「已暂停」；全屏只藏操作栏和质量栏 | 点暂停、全屏 | 钮会亮、会切换。舞台不画「已暂停」。全屏只藏侧栏，洞仍是底色 |

## 本机环境（核对时不要当成应用缺陷）

- 嵌套 KVM 创建 vCPU 会触发宿主机内核错误。模拟器必须 `-accel off`（TCG）。
- 没有 `/dev/dri`。`libva` 在，打不开解码设备。
- `google_apis` API 34 首启会在 `system_server` 看门狗里循环，卷不挂载。文件和投屏用 `aosp_atd` 且 `sys.boot_completed=1` 之后再记通过或失败。
