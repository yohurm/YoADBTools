## 本机环境（核对时不要当成应用缺陷）

- 嵌套 KVM 创建 vCPU 会触发宿主机内核错误。模拟器必须 `-accel off`（TCG）。本次没有重新打开 KVM。
- 没有 `/dev/dri`。`libva` 在，打不开解码设备。投屏像素因此保持阻塞。
- `google_apis` API 34 首启会在 `system_server` 看门狗里循环。本次文件和投屏都记在 `aosp_atd` 且 `sys.boot_completed=1` 之后。
